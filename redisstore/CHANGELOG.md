# Changelog

Release notes for `github.com/tlmanz/authkit/redisstore/v2`, tagged
`redisstore/vX.Y.Z`. Each `## [vX.Y.Z]` section becomes that version's GitHub
release notes (see [../RELEASING.md](../RELEASING.md)). Dates are MM/DD/YY.

## [v2.0.0] - 07/19/26

First release of the Redis-backed stores for authkit v2: server-side sessions,
login throttling, trusted devices and PKCE authorization codes.
